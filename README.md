Archived
========

This repository used to house the grml-autoconfig framework of the [Grml](http://grml.org) project.
The config framework is for the main bootup process of a grml system.

This repository was merged into grml-live, see https://github.com/grml/grml-live.

Further information on grml-autoconfig is available from http://grml.org/config/grml-autoconfig.1.html
